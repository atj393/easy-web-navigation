  THE RELEASE BLOCKER (RB-001)
    The popup resized itself ~30 times over ~0.75s every time it opened.
    Cause: `.popup { width: min(420px, calc(100vw - 32px)); padding: 20px }`
    with no box-sizing and no width on html/body. An extension popup is
    auto-sized by the browser, so `100vw` IS the popup's width -- content width
    depended on popup width and vice versa. Padding outside the declared width
    made each round-trip grow by exactly 8px until min() clamped, which is why
    it settled at 460 rather than the intended 420.
    Fixed by an explicit sizing contract, written at the top of
    apps/extension/entrypoints/popup/style.css. Do not reintroduce viewport
    units in that file; style.test.ts will fail if anyone does.
    Measured in packaged Chromium: 31/6/16 resizes before, 2/2/2 after, and one
    rendered shell width (420) instead of thirty.

  MAIN CHANGES
    - Popup rebuilt as a fixed 420x580 shell: pinned header + primary action,
      Results / Guides / Automatic tabs, scrolling body, pinned report actions.
      Startup is now one reducer with an explicit boot phase (state.ts).
    - Rule corrections. False positives: disabled/aria-disabled controls, inert
      subtrees, roving-tabindex widgets, icon buttons labelled on the icon,
      invalid tabindex, <details>, hidden markup in positive-tabindex.
      False negatives: unlabeled <select>/<textarea> named by their own
      contents, decorative aria-hidden glyphs counted as names, controls inside
      a hidden shadow host.
    - Options page: all four settings were dead. "Disabled domains" claimed the
      extension stayed inactive on those sites and was never read -- now
      enforced in popup, background and content script. "Show WCAG references"
      now drives the popup and reports. The other two were removed.
    - Firefox: MV2 has no optional_host_permissions, so the site/all-sites
      scopes could never be granted there. Same optional access now declared
      under optional_permissions. REQUIRED PERMISSIONS UNCHANGED.
    - Performance: keyboard path with 500 markers 582ms -> 124ms on a page with
      1801 focusable elements. Overlay drawing is read-then-write with one
      batched append; scans memoise style lookups per pass.
    - Popup a11y: aria-controls dangled on 2 of 3 tabs (only the selected panel
      was rendered); heading levels skipped H1 -> H3. Both fixed.
