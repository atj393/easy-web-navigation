Easy Web Navigation — Demo Sites

Static pages used to exercise keyboard accessibility inspection. Some pages contain deliberate keyboard problems so the tool has something to find in later phases.

  • Semantic good page — a clean baseline.
  • Broken keyboard page — unreachable controls.
  • Fake buttons page — divs pretending to be buttons.
  • Modal focus trap page — a trapping dialog.
  • Form labels page — labeled vs. unlabeled inputs.
  • Correct widgets page — patterns that are built properly and must not be reported: roving-tabindex tabs, menus and radio groups, disabled and inert controls, icon buttons labelled on the icon, and a component whose host is hidden.
  • Large tab order page — over a thousand controls, for comparing the keyboard-path marker limits and for spotting slow marker drawing.
  • SPA routes page — pushState, replaceState, hash changes, Back/Forward, a full <main> replacement, and one DOM change with no URL change at all.

The correct-widgets page is the important one to run after changing a rule: everything on it is correct, so anything reported there is a false positive.
